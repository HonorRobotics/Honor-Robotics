# Honor-Robotics
Honor Robotics represents HONOR's venture into embodied artificial intelligence.



|          Title          | Description                                                  |      |
| :---------------------: | ------------------------------------------------------------ | ---- |
|       Locomotion        | **honor_rl_lab**:  A reinforcement learning-based whole-body control framework for Honor robots, powered by IsaacLab and the IsaacSim physics engine. https://github.com/HonorRobotics/honor_rl_lab |      |
|                         | **honor_rl_mjlab**:  A reinforcement learning-based whole-body control framework for Honor robots, powered by mjlab and the MuJoCo physics engine.https://github.com/HonorRobotics/honor_rl_mjlab |      |
|     honor_rl_deploy     | **honor_rl_deploy**: RL policy deployment (C++) for Honor robots including controller, FSM and a set of ROS2 topics, which can drive Mujoco and the real robot identically. |      |
|      honor_mujoco       | **honor_mujoco**: Mujoco simulation for Honor robots, which has the same ROS2 topics and controller as the real robot. |      |
| honor_robot_description | **honor_robot_description**: URDF & MJCF robot description package for Honor robots. |      |
|     honor-robot-sdk     | **honor-robot-sdk**: ROS2 development SDK for Honor robots. Provides message interfaces (topic/service/action), C++/Python examples, and iceoryx + CycloneDDS middleware for external development.https://github.com/HonorRobotics/honor-robot-sdk |      |
